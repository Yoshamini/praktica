    <h1>Начальный сайт</h1>
    
    <h1>HTML</h1>
    <h2>Что это такое и что входит в это?</h2>
    <p>HTML - язык разметки для создания веб-страниц. Он определяет структуру и содержание страницы с помощью специальных элементов.</p>
    
    <h2>Основные элементы HTML</h2>
    
    <h3>1. Структура документа</h3>
    <ul>
        <li>Декларация типа документа</li>
        <li>Корневой элемент страницы</li>
        <li>Служебная информация (заголовок, метаданные)</li>
        <li>Видимое содержимое страницы</li>
    </ul>
    
    <h3>2. Заголовки</h3>
    <p>Уровни заголовков от 1 до 6, где уровень 1 - самый важный:</p>
    <h1>Заголовок 1 уровня</h1>
    <h2>Заголовок 2 уровня</h2>
    <h3>Заголовок 3 уровня</h3>
    <h4>Заголовок 4 уровня</h4>
    <h5>Заголовок 5 уровня</h5>
    <h6>Заголовок 6 уровня</h6>
    <p>Тег: &lt;h1&gt; до &lt;h6&gt;</p>
    
    <h3>3. Текстовые элементы</h3>
    <ul>
        <li>Абзац текста</li>
        <li>Важный текст (жирный)</li>
        <li>Выделенный текст (курсив)</li>
        <li>Ссылки на другие страницы или ресурсы</li>
    </ul>
    
    <h2>Зачем нужен HTML?</h2>
    <ol>
        <li>Структура - организует содержимое страницы</li>
        <li>Семантика - придает смысл элементам (заголовок, абзац, список)</li>
        <li>Доступность - помогает специальным программам понимать страницу</li>
        <li>Поисковая оптимизация - поисковые системы анализируют структуру</li>
        <li>Основа для стилей и интерактивности - без HTML не было бы оформления и динамики</li>
    </ol>
    
    <h2>Как работает HTML?</h2>
    <p>Браузер читает HTML-код и отображает его как веб-страницу. Каждый элемент говорит браузеру, какую роль играет определенный фрагмент содержимого.</p>
    
    <p>HTML работает вместе с:</p>
    <ul>
        <li>CSS для оформления и дизайна</li>
        <li>JavaScript для добавления интерактивности</li>
    </ul>
    
    <p>Это три основных технологии для создания современных веб-сайтов.</p>
